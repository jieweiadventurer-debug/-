# Music source and build

relay-loop.mp3 is an 8-second original sequence of synthesized triangle/sine tones generated by tools/compose-music.py. No third-party music, sampled recordings, or downloaded sound libraries were used. The source note sequence and synthesis remain in this project; no third-party track license is asserted.

Build with Python3 and an external FFmpeg executable with libmp3lame:

    python3 tools/compose-music.py --ffmpeg /absolute/path/to/ffmpeg

The lossless 16kHz mono PCM16 source is tools/fixtures/music-source.wav, excluded from the phone package by the tools folder ignore. It is retained as a source/alternative if a target device cannot decode MP3; that would require a separately validated WAV package rather than silently inflating the music subpackage. The standard music subpackage contains only the MP3 and entry JS, with an audio budget of 100KiB.

MP3 is 64kbps with Xing/LAME encoder delay metadata. Host decoding checks do not establish seamless looping in WeChat; **iPhone/Android loop gaps and interruption recovery require real-device listening**. FFmpeg is a build-time tool installed outside the project; no encoder binaries or dependencies enter the game package. Default-off music and independent sound/vibration preferences remain unchanged.
